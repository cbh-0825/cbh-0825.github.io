# cbh-0825.github.io# 自我介紹

大家好，我是柏翰，目前就讀於**新竹市立光武國民中學自然科學資優班**。我對自然科學、資訊科技與程式設計都有濃厚的興趣，平時除了學校課程之外，也會利用自己的時間主動學習不同的程式語言、開發工具以及電子實作技術。我喜歡透過實際操作、實驗與除錯來理解問題，而不只是記住最後的答案。

在程式設計方面，我目前接觸過 **Java、JavaScript、Python 與 C++**。其中，我曾經花較多時間學習 Java，並準備 **Oracle Java 1Z0-819** 相關內容。我對 Java 的語法規則、類別與物件、`package`、`import`、例外處理、陣列以及程式的編譯與執行方式都有進一步研究。學習 Java 的過程中，我也發現自己很喜歡研究一些容易被忽略的語言規則，例如不同程式結構在什麼情況下可以編譯、什麼情況下會產生例外，以及不同語法之間的關係。

除了 Java 之外，我也會使用 **JavaScript** 進行網頁上的程式操作，例如透過 DOM 取得 HTML 元素、處理文字、操作剪貼簿以及撰寫簡單的非同步程式。我也接觸過 **Python**，並學習如何在電腦上建立與執行 Python 程式。透過接觸不同語言，我逐漸發現不同程式語言雖然語法和設計理念有所不同，但背後許多程式設計概念是可以互相連結的。

我也對**電腦硬體與電子實作**很有興趣。目前我有使用 Arduino UNO 進行學習，並接觸過 RC522 RFID 模組。我希望不只是知道「程式怎麼寫」，也能理解程式如何與實際的電子元件互動。因此，我會研究 Arduino 的 C++ 程式、硬體介面、通訊方式以及相關函式庫。學習 RFID 的過程中，我也曾進一步研究磁扣或感應卡如何從讀卡機取得能量，並將這個問題與物理學中的**法拉第電磁感應定律**連結起來。

自然科學也是我非常重要的興趣之一。我喜歡把課堂中學到的科學原理與生活中的實際技術連結。例如看到 RFID、感應卡、電子元件等設備時，我會進一步思考它們背後涉及哪些物理原理，而不是只把它們當成可以直接使用的黑盒子。這種從「實際現象」追問到「背後原理」的學習方式，也是我在自然科學與資訊科技學習上的特色。

在學習過程中，我也很重視**自主研究與問題解決能力**。當遇到程式錯誤或軟體無法正常執行時，我通常會先觀察錯誤訊息，再嘗試分析原因、修改程式並重新測試，而不是直接放棄。我也會查閱官方文件、技術資料或透過實際實驗確認自己的推論。對我而言，除錯不只是把錯誤修好，而是一個理解程式與系統運作方式的過程。

由於我目前使用的電腦設備較舊，部分新版本的開發工具並不支援我的環境，因此我也因此學習到另一種能力：**在有限的條件下尋找可行的技術方案**。例如選擇適合 Windows 7 的軟體版本、確認程式語言與開發工具的相容性，以及尋找可以在現有設備上使用的替代方案。這些經驗讓我更加理解，實際的資訊科技不只是寫程式，也包含環境設定、相容性、除錯與系統管理。

近來我也開始關注**人工智慧與程式開發的結合**，例如 GitHub Copilot、OpenAI Codex 以及其他 AI 程式碼工具。我認為 AI 不應該只是用來直接產生答案，而可以作為學習與除錯的輔助工具。當 AI 提供一段程式時，我仍然會希望理解程式為什麼這樣寫、有哪些限制，以及如果換一種方式是否能得到相同或更好的結果。

我希望未來能繼續在**程式設計、資訊科技、自然科學與電子實作**之間探索。我目前不想把自己限制在單一領域，而是希望逐漸建立從物理原理、硬體、程式到軟體應用的完整理解。例如未來可以進一步學習更深入的 C++、資料結構、演算法、嵌入式系統、網路技術以及人工智慧等領域。

對我而言，學習不只是取得一個標準答案，而是理解「**為什麼會這樣，以及還能不能用另一種方法做到**」。我希望透過持續實作、實驗與自主研究，逐漸累積自己的技術能力，並把自然科學與程式設計結合起來，發展出能夠真正解決問題的能力。
